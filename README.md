# HP Prime Games

Nine original games for the **HP Prime** graphing calculator, written in Python (the `hpprime` module). Each one is a calculator app that you open from the Apps screen. They all work with the touch screen and the keyboard.

## How to install

1. Download the zip for a game, or the whole repo with the green **Code → Download ZIP** button, and unzip it.
2. Connect your HP Prime to a computer and open the **HP Connectivity Kit**.
3. Drag the game's `.hpappdir` folder (for example `RAILCAB.hpappdir`) onto your calculator in the Connectivity Kit. On some versions you drag it into the **Application Library** section.
4. On the calculator, press **Apps** and open the game.

Each game folder has a `README.txt` with its controls.

## Notes

- Made for the HP Prime G2. Some of the bigger games need a fair amount of Python memory.
- High scores and saves are stored in small `.txt` files inside each app.
